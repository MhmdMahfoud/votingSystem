# votingSystem
Beauty Pageant Management System
A comprehensive web application for managing beauty pageant competitions, from contestant registration to jury scoring and result calculation.

Key Features
🎭 Event Management: Create and configure pageant events with custom scoring rounds

👑 Contestant Profiles: Manage contestant information with photo uploads

👩‍⚖️ Jury Portal: Secure login for judges with event-specific scoring capabilities

📊 Real-time Scoring: Dynamic score submission with percentage-based rounds

🏆 Results Calculation: Automatic calculation of weighted scores across multiple rounds

📱 Responsive Design: Works on desktop and mobile devices
